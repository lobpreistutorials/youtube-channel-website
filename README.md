# LOBPREIS TUTORIALS

Eine moderne Landingpage für einen YouTube-Kanal mit Fokus auf:
- Covers
- Gitarren-Tutorials
- Sound & Technik
- Lernpfade und Downloads

## Projektstruktur
- `index.html` – Startseite der Website
- `style.css` – Styling und Layout
- `assets/` – Platz für Bilder, Logos oder Cover-Assets

## So kannst du die Seite lokal öffnen
1. Lade das Projekt herunter oder klone es.
2. Öffne `index.html` direkt im Browser.
3. Optional: Nutze einen lokalen Webserver wie `python -m http.server`.

## Beispiel
```bash
python -m http.server 8000
```
Danach im Browser auf:
`http://localhost:8000`

## Anpassungen
- Kanalname, Texte und Farben kannst du in `index.html` und `style.css` anpassen.
- Du kannst weitere Cover- oder Video-Abschnitte ergänzen.
- Bilder und Logos kannst du in `assets/` ablegen.
